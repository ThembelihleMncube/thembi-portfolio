# Thembelihle Mncube — Portfolio

Personal portfolio for my software engineering, data analytics, data engineering and applied AI work.

## Highlights
- Responsive React and Tailwind CSS site with light and dark themes.
- Portfolio sections for skills, experience, projects, education and certifications.
- A direct email link for visitors to request my CV.
- GitHub Pages deployment and a production build check on pull requests.

## Run locally
```bash
git clone https://github.com/ThembelihleMncube/thembi-portfolio.git
cd thembi-portfolio
npm ci
npm run dev
```

## Build
```bash
npm ci
npm run build
npm run preview
```

## Deploy
GitHub Pages builds and deploys the `main` branch using GitHub Actions. The build output is `dist/`. Netlify can use the same build command and output directory.
